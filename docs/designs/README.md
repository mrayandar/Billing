# Screen designs

Each `.dc.html` file is one screen from the design canvas. Read them as layout and content references: the sections, labels, fields, buttons, keyboard hints and sample numbers are what to build. Do not copy their markup or the `support.js` line; build the real screens with Next.js and Tailwind.
